# Manual STL verification fixtures

Generated by `scripts/generate-fixtures.ts`. Open each file in Bambu Studio
(or OrcaSlicer/PrusaSlicer) and confirm the reported size matches the expected
value below. All units are millimeters -- this checks that geometry-core's
`1 world unit = 1mm` convention survives the real STL export path unchanged.

## cube_18x18x10.stl
Expect bounding box exactly **18 x 18 x 10 mm** in the slicer.

## cylinder_d14.stl
Expect bounding box exactly **14 x 14 x 20 mm** (X/Y diameter x height).
64 radial segments, so the polygon-vs-true-circle diameter error is negligible.

## translated_rotated_cube.stl
18x18x10mm cube, design transform = position (37.5, -12, 8)mm, rotate 30deg about Z.
Expect bounding box approx **24.59 x 24.59 x 10.00 mm** (footprint widened by the 30deg rotation; height unchanged). The point of this fixture is confirming the *position* in the slicer's build plate matches (centroid roughly at X=37.5, Y=-12, Z=8 from plate origin, modulo the slicer's own origin convention) -- i.e. the transform was baked into the file, not lost.

## split_part_a.stl + split_part_b.stl
A 20x20x40mm cube (positioned at design X=10, Y=5) split in half by the Z=0 plane. **Import both files into the same slicer project without moving either one** -- they should sit flush against each other and reconstruct one 20x20x40mm block at the same plate position, with no gap and no overlap.
Part A: watertight=true, open edges=0, non-manifold edges=0.
Part B: watertight=true, open edges=0, non-manifold edges=0.
Combined volume should read as ~16000 mm^3 total in the slicer if it reports part volumes.
